# Desktop Groups для Windows 11

Соберите ярлыки, файлы и папки в сворачиваемые группы прямо на рабочем столе. У каждой группы своё место, название и оформление.

**[Скачать установщик для Windows 11 x64](https://github.com/LDY55/DesktopGroups/releases/download/v1.8.0/DesktopGroups-1.8.0-Setup-x64.exe)** · [Переносная версия ZIP](https://github.com/LDY55/DesktopGroups/releases/download/v1.8.0/DesktopGroups-1.8.0-win-x64.zip) · [Все выпуски](https://github.com/LDY55/DesktopGroups/releases)

## Начало работы

1. Запустите установщик и откройте **Desktop Groups** из меню «Пуск». Для переносной версии распакуйте весь ZIP в отдельную папку и запустите `DesktopGroups.exe`. Обе сборки содержат среду .NET.
2. Перетащите ярлык в группу «Работа». Двойной щелчок по ярлыку откроет его. Чтобы создать ещё одну группу, щёлкните правой кнопкой значок Desktop Groups возле часов и выберите **Создать группу**.
3. Чтобы при перетаскивании убирать личные ярлыки с рабочего стола, включите эту опцию в **Настройки → Перенесённые ярлыки**. Там же можно вернуть их на рабочий стол. Файлы и папки по умолчанию остаются на своих местах.

## Оформление и сетка

В меню группы **… → Оформление** можно выбрать гладкое или рифлёное стекло, отдельно настроить тонировку, размытие обоев и блики. Флажок **Общее оформление для всех групп** применяет выбранный вид ко всем группам.

В **Настройки → Сетка групп** можно включить привязку при перемещении и изменении размера. Шаг сетки — 8, 16, 32 или 64 логических пикселя. Кнопка **Выровнять группы сейчас** выравнивает все незакреплённые группы одним нажатием.
